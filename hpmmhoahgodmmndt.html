as it does not create new economic value but does destroy old economic value

robbery involves exactly 2 types of persons: robber and victim; they work against each other; the robber tries to get value from the victim, the victim tries to keep that value by itself;

during this activity they:

sacrifice existing value [time, material tools, safety, ...];

do not create any new value;

it is obvious for everybody that the robber does not create new value

but neither does the victim, its maximum potential achievement is to keep what already existed without the robbery

proponents of some robbery say that though the robbing process does not create new economic value but the new distribution of value is better (which is value itself); but i have not met any even remotely plausible reasoning to prove such statement

note: all of this is true even if either

the robber is the state;

the robbing is popular;

the robbing is democratically authorized;
