with (y v = 1 / sqrt (1 - v ^ 2 / c ^ 2))

forward

x' = (y v) * (x - v * t )

t' = (y v) * (t + (v / c ^ 2) * x )

backward [the negativity-change of v]

x = (y v) * (x' + v * t')

t = (y v) * (t' - (v / c ^ 2) * x')

in ASCII "y" is the usual name of the Lorentz factor, because it is visually the closest to the greek gamma character, which is the traditional name

can be derived from elementary space properties like homogeneity, isotropy, ... and relativity
